# 한국어 배우기 · Aprende Coreano

Sitio web interactivo para aprender coreano desde cero hasta nivel C2.

## Características
- 🔤 Sistema de escritura Hangul interactivo
- 🔊 Audio TTS con pronunciación nativa
- 🃏 Flashcards con volteo 3D
- 🎮 Juego de emparejamiento
- ✅ Quiz por nivel (A1→C2)
- 💬 Diálogos, lecturas y sección de escucha
- 📜 Literatura y proverbios coreanos
